# ARG035: The JSON binder needs System.Text.Json

## Summary
A class sets `EmitJsonBinder`, but the project does not reference System.Text.Json.

## Cause
This error occurs when `EmitJsonBinder = true` is set on a `ParameterCollection` or `CommandApp` attribute and the type `System.Text.Json.JsonElement` cannot be found in the project.

The generated `Bind` methods take the arguments of a tool call as a `JsonElement` (or a dictionary of them), so the code they are in needs System.Text.Json. It is part of .NET Core 3.0 and later, so a project that targets one of those has it; a project that targets .NET Framework or netstandard2.0 needs the package. The runtime library of the parser does not reference it, so only projects that use the binder need it. Without this rule the generated code would fail to compile with errors about missing types.

## How to fix
Add the System.Text.Json package to the project:

```xml
<ItemGroup>
	<PackageReference Include="System.Text.Json" Version="8.0.5" />
</ItemGroup>
```

Or remove `EmitJsonBinder` when the class does not need to be bound from JSON:

```csharp
// Before - Error (in a netstandard2.0 project without System.Text.Json):
[ParameterCollection(EmitJsonBinder = true)]
public partial class MyArgs { }

// After - Fixed:
[ParameterCollection]
public partial class MyArgs { }
```
