# ARG030: Parse method not found

## Summary
The method named by the `ParsedWithMethod` attribute does not exist, is not accessible, or does not have the form of a `TryParse` method.

## Cause
This error occurs when a property with `Option` or `Positional` and `ParsedWithMethod("Name")` has no usable static method `Name`. The generator looks for the method in two places, in this order:
1. The class that declares the property (including the base classes it inherits static methods from). The method can be private, and this is the only place for a type you cannot add methods to, such as `int?`.
2. The type of the property, for example `Point.TryParse` for a property of type `Point`.

A usable method is static, not generic, returns `bool` and takes two parameters: the text of the argument and an `out` parameter for the value.

## How to fix
Add the method, or correct its name, signature or accessibility. When the property is nullable, declaring the `out` parameter as nullable lets the method answer `null`:

```csharp
// Before - Error: there is no method ParseDescriptor
[Option("r", "redirectOutputStream", "File descriptor to send output to, NULL for none")]
[ParsedWithMethod("ParseDescriptor")]
public int? RedirectOutputStream { get; set; } = 1;

// After - Fixed:
[Option("r", "redirectOutputStream", "File descriptor to send output to, NULL for none")]
[ParsedWithMethod("ParseDescriptor")]
public int? RedirectOutputStream { get; set; } = 1;

private static bool ParseDescriptor(string input, out int? value)
{
	if (input == "NULL")
	{
		value = null;
		return true;
	}
	var parsed = int.TryParse(input, out var descriptor);
	value = parsed ? descriptor : null;
	return parsed;
}
```
