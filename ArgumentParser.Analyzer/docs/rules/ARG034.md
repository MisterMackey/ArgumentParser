# ARG034: Two arguments have the same key in a JSON Schema

## Summary
The arguments of a JSON Schema need different keys. The key of an argument is the name of its property in camelCase.

## Cause
This error occurs when the JSON Schema of a class or of a command would hold two arguments with the same key. It is only reported when the schema or the binder is emitted: `EmitMcpManifest` or `EmitJsonBinder` on the `ParameterCollection` attribute of a class on its own, or on the `CommandApp` attribute of a tree.

- In one class, two properties whose names differ only in the case of their first letters, such as `Name` and `name`, or `URL` and `Url` (both `url`).
- In a tree of commands, the schema of a leaf also holds the options and flags of the root and of every group on the way to it, so a property of the leaf (or of a group) cannot have the key of a property of a command above it. Commands side by side may share keys.

The keys are the property names, not the long names of the arguments, so two arguments with different long names can still have the same key.

The diagnostic is reported on the property that comes later: the one in the lower command, or the later one in the class.

## How to fix
Rename one of the properties, or leave one of them out of the schema with the `ExcludeFromManifest` attribute when the program sets it itself.

```csharp
// Before - Error:
[CommandApp("app", EmitMcpManifest = true)]
public partial class App
{
	[Option("n", "name", "Name of the profile")]
	public string Name { get; set; } = "";

	public Create? Create { get; private set; }
}

[ParameterCollection]
[Command("create", "Create an item")]
public partial class Create
{
	[Positional(0, "Name of the item", true)]
	public string Name { get; set; } = "";
}

// After - Fixed:
[CommandApp("app", EmitMcpManifest = true)]
public partial class App
{
	[Option("n", "name", "Name of the profile")]
	public string Profile { get; set; } = "";

	public Create? Create { get; private set; }
}
```
