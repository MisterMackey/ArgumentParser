# ARG028: Help setting not supported by a command tree

## Summary
The `CommandApp` attribute can only use the help settings for which the generator writes the help text of every level of the tree.

## Cause
This error occurs when the `CommandApp` attribute uses:
- `HelpTextGeneration.GenerateArgumentOnly` or `HelpTextGeneration.GenerateArgumentAndHandler`, in which the user writes the help text, or
- `HelpTextGeneration.None` together with `BehaviourOnError.DisplayHelpAndExit` (the default), which has to display a help text on an error but has none.

A tree has a help text for the root, every group and every leaf, so writing them by hand is not supported (yet).

## How to fix
Use `GenerateAll` (the default: help text, plus a help argument that shows it on every level), `GenerateTextOnly` (only the `CommandHelpText` constants), or `None` with another `BehaviourOnError`.

```csharp
// Before - Error:
[CommandApp("app", "An app", HelpTextGeneration.None)]
public partial class App
{
	public Run? Run { get; private set; }
}

// After - Fixed:
[CommandApp("app", "An app", HelpTextGeneration.None, behaviourOnError: BehaviourOnError.ThrowIfAnyError)]
public partial class App
{
	public Run? Run { get; private set; }
}
```
