# ARG025: Required member on a command group

## Summary
The root of a command tree and its command groups cannot have members with the `required` modifier.

## Cause
This error occurs when a class with the `CommandApp` attribute, or with the `Command` attribute but without the `ParameterCollection` attribute, has a property or field with the `required` modifier.

The generated parser creates the root and the groups on the path the user typed with `new`, and does not set anything but their options and flags. The C# compiler refuses `new` for a class with required members that are not set.

A command that is required is also not something the command line can express: the user either types the name of a command or does not. To make an option required, use the `required` argument of the `Option` attribute.

## How to fix
Remove the `required` modifier. Give the member a default value if it needs one.

```csharp
// Before - Error:
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public required string Root { get; set; } // Error: required
	public CreateDirectory? Create { get; private set; }
}

// After - Fixed:
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	[Option("r", "root", "Directory to work in", required: true)]
	public string Root { get; set; } = "";
	public CreateDirectory? Create { get; private set; }
}
```
