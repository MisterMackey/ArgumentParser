# ARG021: Leaf command with child commands

## Summary
A class with the `ParameterCollection` attribute is a leaf of the command tree and cannot have child commands.

## Cause
This error occurs when a class with the `Command` and the `ParameterCollection` attribute has a property whose type is a command class.

The arguments left after the command words are parsed by the leaf. If it also had child commands, the first positional argument would be both a value for the leaf and the name of a command.

## How to fix
Either:
1. Remove the `ParameterCollection` attribute to turn the class into a command group (options stay available, positional arguments do not), or
2. Remove the property, or move the child command to a group above the leaf.

```csharp
// Before - Error:
[ParameterCollection]
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public CreateDirectory? Create { get; private set; } // Error: a leaf cannot have children
}

// After - Fixed (Option 1):
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public CreateDirectory? Create { get; private set; }
}
```
