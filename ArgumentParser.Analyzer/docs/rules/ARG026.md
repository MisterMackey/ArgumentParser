# ARG026: Argument of a command class type

## Summary
A property with the `Option`, `Flag` or `Positional` attribute cannot have a command class (a class with the `Command` or `CommandApp` attribute) as its type.

## Cause
This error occurs when an argument property, in any class, has a type with the `Command` or `CommandApp` attribute.

A property whose type is a command class declares a child command of its class. An argument attribute on it would make it an argument at the same time, and a command class cannot be parsed from a single command line value. In a class of the tree the property is not linked as a child command, and the rules it would trigger there (ARG020, a group without commands, and ARG019, an unreachable command) are not reported for it.

## How to fix
Either:
1. Remove the argument attribute, so the property is a child command, or
2. Give the argument a type that is not a command class: keep the argument attributes and the command attributes on separate types.

```csharp
// Before - Error:
[CommandApp("app", "An app")]
public partial class App
{
	[Option("r", "run", "What to run")]
	public RunCommand? Run { get; private set; } // Error: RunCommand has the Command attribute
}

// After - Fixed (Option 1):
[CommandApp("app", "An app")]
public partial class App
{
	public RunCommand? Run { get; private set; }
}
```
