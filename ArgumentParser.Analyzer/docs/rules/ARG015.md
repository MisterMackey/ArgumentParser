# ARG015: Positional argument on a class with child commands

## Summary
A command group or the root of the command tree cannot have positional arguments.

## Cause
This error occurs when a class with the `CommandApp` attribute, or with the `Command` attribute but without the `ParameterCollection` attribute, has a property with the `Positional` attribute.

On the command line, the first argument that is not an option or a flag after the options of such a class is the name of the next command. That leaves no place for a positional argument of the class itself.

## How to fix
Either:
1. Move the positional argument to the leaf command (the class with the `ParameterCollection` attribute) that needs it, or
2. Make it an `Option`, which is recognized by its name and can come before the name of the next command.

```csharp
// Before - Error:
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	[Positional(0, "Name of the directory")] // Error: a group cannot have positional arguments
	public string Name { get; set; } = "";
}

// After - Fixed (Option 1):
[ParameterCollection]
[Command("create", "Create a directory")]
public partial class CreateDirectory
{
	[Positional(0, "Name of the directory")]
	public string Name { get; set; } = "";
}

// After - Fixed (Option 2):
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	[Option("n", "name", "Name of the directory")]
	public string Name { get; set; } = "";
}
```
