# ARG027: Argument name used by a parent command

## Summary
An option or flag of a command cannot have a short or long name that a command above it in the tree (its group, their groups, the root) already uses, or a name of the help argument of the tree.

## Cause
This error occurs when a class of the command tree has an `Option` or `Flag` property whose short or long name is also the short or long name of an option or flag of one of the classes the command is part of.

The options of each level come before the next command word, so the parser would not mix them up, but a person would: `app -v build -v` would mean two different things, and a help text that shows the options of the commands above a leaf would show the name twice. Commands that are not above one another, such as two children of one group, may use the same names.

The help argument of the tree (set by the `CommandApp` attribute, `-h` and `--Help` by default) is accepted on every level, so no option or flag anywhere in the tree, the root included, can use its names. This only applies with `HelpTextGeneration.GenerateAll` (the default), the only mode with a help argument. Names are compared exactly: `--help` does not collide with `--Help`.

## How to fix
Rename one of the two arguments, or keep only the one on the command above, which applies to every command below it. For a collision with the help argument, rename the option or flag, or give the help argument other names on the `CommandApp` attribute.

```csharp
// Before - Error:
[CommandApp("app", "An app")]
public partial class App
{
	[Flag("v", "verbose", "Show more output")]
	public bool Verbose { get; set; }

	public Build? Build { get; private set; }
}

[ParameterCollection]
[Command("build", "Build the project")]
public partial class Build
{
	[Flag("v", "verify", "Verify the output")] // Error: 'v' is used by App
	public bool Verify { get; set; }
}

// After - Fixed:
[ParameterCollection]
[Command("build", "Build the project")]
public partial class Build
{
	[Flag("c", "verify", "Verify the output")]
	public bool Verify { get; set; }
}
```

```csharp
// Before - Error:
[CommandApp("app", "An app")]
public partial class App
{
	[Option("h", "host", "The server to use")] // Error: 'h' is the short name of the help argument
	public string Host { get; set; } = "";

	public Build? Build { get; private set; }
}

// After - Fixed (either rename the option, or move the help argument):
[CommandApp("app", "An app", helpArgumentShortName: "?")]
public partial class App
{
	[Option("h", "host", "The server to use")]
	public string Host { get; set; } = "";

	public Build? Build { get; private set; }
}
```
