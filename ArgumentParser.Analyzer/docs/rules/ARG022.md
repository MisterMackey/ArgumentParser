# ARG022: Child command property cannot be set

## Summary
A property that declares a child command needs a setter that the generated code can call.

## Cause
This error occurs when a property whose type is a command class has no setter, or only an `init` setter.

The generated `Parse` creates the child object for the command that was typed and assigns it to the property of its parent. A getter-only property cannot be assigned, and an `init` setter can only be called while an object is being created.

## How to fix
Give the property a private setter. The generated code is part of the same class, so it can call it, and users of the class cannot replace the child.

```csharp
// Before - Error:
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	public IngredientAdd? Add { get; } // Error: no setter
}

// After - Fixed:
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	public IngredientAdd? Add { get; private set; }
}
```
