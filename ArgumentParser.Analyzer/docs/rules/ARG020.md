# ARG020: Command group without commands

## Summary
A command group or the root of the tree needs at least one child command.

## Cause
This error occurs when a class with the `CommandApp` attribute, or with the `Command` attribute but without the `ParameterCollection` attribute, has no property whose type is a command class.

Such a class cannot do anything: there is nothing to select after its options.

Only the properties the class declares itself count. A property that is inherited from a base class is not seen, so a group whose children are all declared in a base class has no child commands as far as the generator knows. Declare the properties in the class that has the `CommandApp` or `Command` attribute.

## How to fix
Either:
1. Add a property whose type is a command class, or
2. Add the `ParameterCollection` attribute if the class should be a leaf command that does the work itself.

```csharp
// Before - Error:
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup { }

// After - Fixed (Option 1):
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	public IngredientAdd? Add { get; private set; }
}

// After - Fixed (Option 2):
[ParameterCollection]
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	[Option("n", "name", "Name of the ingredient")]
	public string Name { get; set; } = "";
}
```
