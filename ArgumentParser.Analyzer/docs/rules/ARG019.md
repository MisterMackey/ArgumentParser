# ARG019: Command class is not part of a tree

## Summary
A class with the `Command` attribute that cannot be reached from a class with the `CommandApp` attribute is never selected.

## Cause
This warning occurs when no property chain leads from a `CommandApp` class to the command class. Common reasons are that the property that declares it in its parent is missing, or that the parent itself is not part of a tree.

A class with both `Command` and `ParameterCollection` still gets its own `Parse` method, so it can be used on its own. The warning is a hint that the `Command` attribute does nothing in that case.

## How to fix
Add a property with the type of the command class to its parent, or remove the `Command` attribute.

```csharp
[CommandApp("myFileManagingTool", "Manage files and directories")]
public partial class FileTool
{
	public ListFiles? List { get; private set; } // makes ListFiles part of the tree
}

[ParameterCollection]
[Command("list", "List the files")]
public partial class ListFiles { }
```
