# ARG032: The elements of a list cannot be nullable value types

## Summary
The elements of a `List<T>` argument cannot be of a nullable value type such as `int?`.

## Cause
This error occurs when an `Option` or a `Positional` has a type like `List<int?>`. Every value on the command line becomes one element of the list, so an element is always a value that was given and is never `null`.

## How to fix
Use the type without the question mark for the elements. If the list itself can be absent, make the list nullable instead: it is then `null` when no value was given.

```csharp
// Before - Error:
[Option("n", "number", "The numbers")]
public List<int?> Numbers { get; set; } = new();

// After - Fixed:
[Option("n", "number", "The numbers")]
public List<int>? Numbers { get; set; }
```

The annotation of a reference type (`List<string?>`) is not reported: it says nothing about the parsing.
