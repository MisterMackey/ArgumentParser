# ARG031: A list positional must be the last positional

## Summary
A positional argument of type `List<T>` takes every value that is left, so no positional argument can come after it.

## Cause
This error occurs when a property of type `List<T>` has a `Positional` attribute and another `Positional` has a higher position. On the command line, `myApp a b c` gives all three values to the list; there would be no way to tell where the list ends and the next positional begins.

## How to fix
Give the list the highest position, or use an option for the list, which can be repeated in any place of the command line (`myApp --file a --file b`).

```csharp
// Before - Error:
[Positional(0, "The files")]
public List<string> Files { get; set; } = new();

[Positional(1, "The target")]
public string Target { get; set; } = "";

// After - Fixed:
[Positional(0, "The target")]
public string Target { get; set; } = "";

[Positional(1, "The files")]
public List<string> Files { get; set; } = new();
```

Only one positional can be a list, as only one can be the last.
