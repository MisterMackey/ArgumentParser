# ARG014: Invalid command name

## Summary
The name given to the `Command` attribute is not a word that users can type as a command.

## Cause
This error occurs when the name of a command is empty, contains whitespace, or starts with `-`.

Command names are matched against the arguments on the command line, one word at a time. A name with whitespace could never match a single argument, and a name that starts with `-` would be read as an option or a flag.

The name of the application in the `CommandApp` attribute is not checked: it is only displayed in help text.

## How to fix
Give the command a single word that does not start with `-`. To describe the command in more detail, use the description.

```csharp
// Before - Error:
[ParameterCollection]
[Command("create directory", "Create a directory")] // Error: contains whitespace
public partial class CreateDirectory { }

// After - Fixed:
[ParameterCollection]
[Command("create", "Create a directory")]
public partial class CreateDirectory { }
```

If the command is in a group, give the group its own command class instead of putting both words in one name:
```csharp
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public CreateDirectory? Create { get; private set; }
}
```
