# ARG014: Invalid command name

## Summary
The name given to the `Command` attribute is not a word that users can type as a command.

## Cause
This error occurs when the name of a command:
- is empty or longer than 127 characters,
- starts with `-`,
- contains a character other than the ASCII letters (`A-Z`, `a-z`), the digits, `_`, `-` and `.` (whitespace included),
- or contains `__` (two underscores).

Command names are matched against the arguments on the command line, one word at a time. A name with whitespace could never match a single argument, and a name that starts with `-` would be read as an option or a flag.

A command is also a tool of the Model Context Protocol (MCP) when the application emits a manifest (`EmitMcpManifest`): the tool is named after the path of the command, joined with `__` (`directories__create`). MCP allows tool names of 1 to 128 characters of the letters, digits, `_`, `-` and `.` only, and a `__` in a name would make two paths give the same tool name (`a__b` + `c` and `a` + `b__c`). The rule applies whether or not the manifest is emitted, so turning it on later never breaks the build.

The name of the application in the `CommandApp` attribute is not checked: it is only displayed in help text.

## How to fix
Give the command a single word of letters, digits, `_`, `-` and `.`, that does not start with `-`. Use a single `_` or `-` to join words (`log_entry`, `dry-run`). To describe the command in more detail, use the description.

```csharp
// Before - Error:
[ParameterCollection]
[Command("create directory", "Create a directory")] // Error: contains whitespace
public partial class CreateDirectory { }

// After - Fixed:
[ParameterCollection]
[Command("create", "Create a directory")]
public partial class CreateDirectory { }
```

If the command is in a group, give the group its own command class instead of putting both words in one name:
```csharp
[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public CreateDirectory? Create { get; private set; }
}
```
