# ARG024: Abstract command class

## Summary
A class of a command tree (a class with the `CommandApp` or `Command` attribute) must be a concrete class.

## Cause
This error occurs when a class with the `CommandApp` or `Command` attribute is `abstract` or `static`.

The generated parser creates an object of every class on the path the user typed. It cannot create an abstract class, and a static class cannot hold the parsed values.

## How to fix
Remove the `abstract` (or `static`) modifier. A base class that is not part of the tree can stay abstract.

```csharp
// Before - Error:
[Command("ingredient", "Manage ingredients")]
public abstract partial class IngredientGroup { } // Error: abstract

// After - Fixed:
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	public IngredientAdd? Add { get; private set; }
}
```
