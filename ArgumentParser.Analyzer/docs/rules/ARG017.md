# ARG017: Duplicate command name

## Summary
The child commands of one command group (or of the root) must have different names.

## Cause
This error occurs when two properties of a class with the `CommandApp` or `Command` attribute have different types whose `Command` attributes give them the same name. The word a user types would select both. Two properties with the same type are one command declared twice, which is reported as [ARG018](ARG018.md).

## How to fix
Give one of the two command classes another name.

```csharp
[Command("create", "Create a directory")]
public partial class CreateDirectory { }

[Command("create", "Create a file")] // Error: "create" is already used by a sibling
public partial class CreateFile { }

[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public CreateDirectory? Create { get; private set; }
	public CreateFile? NewFile { get; private set; }
}
```

Using the same name under two different parents is fine: `directories create` and `files create` do not clash.
