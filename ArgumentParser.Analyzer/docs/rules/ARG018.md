# ARG018: Command class used more than once

## Summary
A command class can be the type of a child command property of one class only, and the root of the tree is never a child.

## Cause
This error occurs when:
- the same command class is the type of child command properties in two places, either in two classes or twice in one class, or
- a property has the type of a class with the `CommandApp` attribute, which also covers a command that has one of its ancestors as a child.

The result of a parse is a typed tree with one object per command. A class that appears twice would be filled in twice, and the path that was typed would be ambiguous.

## How to fix
Declare the command in one place. If two groups need the same behaviour, make two command classes, for example with a shared base class.

```csharp
[ParameterCollection]
[Command("delete", "Delete an item")]
public partial class DeleteItem { }

[Command("directories", "Work with directories")]
public partial class DirectoriesCommand
{
	public DeleteItem? Delete { get; private set; }
}

[Command("files", "Work with files")]
public partial class FilesCommand
{
	public DeleteItem? Delete { get; private set; } // Error: DeleteItem already has DirectoriesCommand as its parent
}

// Fixed: one command class per place, sharing the behaviour through a base class
public abstract class DeleteItemBase { }

[ParameterCollection]
[Command("delete", "Delete a directory")]
public partial class DeleteDirectory : DeleteItemBase { }

[ParameterCollection]
[Command("delete", "Delete a file")]
public partial class DeleteFile : DeleteItemBase { }
```
