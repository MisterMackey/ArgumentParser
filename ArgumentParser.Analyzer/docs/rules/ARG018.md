# ARG018: Command class used more than once

## Summary
A command class can be the type of a child command property of one class only, and the root of the tree is never a child.

## Cause
This error occurs when:
- the same command class is the type of child command properties in two places, either in two classes or twice in one class, or
- a property has the type of a class with the `CommandApp` attribute, which also covers a command that has one of its ancestors as a child.

The result of a parse is a typed tree with one object per command. A class that appears twice would be filled in twice, and the path that was typed would be ambiguous.

## How to fix
Declare the command in one place. If two groups need the same behaviour, make two command classes, for example one that derives from the other.

```csharp
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	public IngredientAdd? Add { get; private set; }
}

[Command("meal", "Manage meals")]
public partial class MealGroup
{
	public IngredientAdd? Add { get; private set; } // Error: IngredientAdd already has IngredientGroup as its parent
}
```
