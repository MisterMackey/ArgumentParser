# ARG033: A required argument cannot be excluded from the manifest

## Summary
An option or positional argument with `required: true` cannot have the `ExcludeFromManifest` attribute.

## Cause
This error occurs when a property has both `required: true` on its `Option` or `Positional` attribute and the `ExcludeFromManifest` attribute, in any class: a class on its own, the root, a group or a leaf of a tree of commands.

`ExcludeFromManifest` leaves the argument out of the JSON Schema and the JSON binding (`EmitMcpManifest`, `EmitJsonBinder`), because the program sets it itself instead of the caller of a tool. A tool call can then never give it, so it cannot be required. The rule applies whether or not the class emits a schema.

## How to fix
Remove `required: true`, or remove the `ExcludeFromManifest` attribute if a tool call should give the argument.

```csharp
// Before - Error:
[Option("", "db", "Path to the database", required: true)]
[ExcludeFromManifest]
public string Db { get; set; } = "";

// After - Fixed:
[Option("", "db", "Path to the database")]
[ExcludeFromManifest]
public string Db { get; set; } = "app.db";
```
