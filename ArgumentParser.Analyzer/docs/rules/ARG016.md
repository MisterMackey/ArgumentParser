# ARG016: Conflicting command attributes

## Summary
The `CommandApp` attribute cannot be combined with the `Command` or the `ParameterCollection` attribute.

## Cause
This error occurs when a class has the `CommandApp` attribute together with the `Command` attribute or the `ParameterCollection` attribute.

The class with `CommandApp` is the root of the command tree: it names the application, and the commands are below it. It cannot also be a command in the tree, and it is not a leaf that parses arguments on its own.

## How to fix
Either:
1. Remove the `CommandApp` attribute if the class is a command, or
2. Remove the `Command` / `ParameterCollection` attribute if the class is the root, and put the command in a class of its own.

```csharp
// Before - Error:
[CommandApp("myFileManagingTool")]
[ParameterCollection] // Error: the root cannot also be a leaf
public partial class FileTool { }

// After - Fixed:
[CommandApp("myFileManagingTool")]
public partial class FileTool
{
	public ListFiles? List { get; private set; }
}

[ParameterCollection]
[Command("list", "List the files")]
public partial class ListFiles { }
```
