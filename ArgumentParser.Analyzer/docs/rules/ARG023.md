# ARG023: Generic command class

## Summary
A class of a command tree (a class with the `CommandApp` or `Command` attribute) cannot be generic, and cannot be nested in a generic type.

## Cause
This error occurs when a class with the `CommandApp` or `Command` attribute has type parameters, or is declared inside a type that has them.

The generated parser creates an object of every class in the tree and refers to the classes by name. It cannot choose type arguments, and a property of type `Group<int>` is not the same node as `Group<T>`.

## How to fix
Make the class non-generic. If several commands share behaviour, put it in a generic base class and derive a concrete command class from it.

```csharp
// Before - Error:
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup<T> { } // Error: generic

// After - Fixed:
[Command("ingredient", "Manage ingredients")]
public partial class IngredientGroup
{
	public IngredientAdd? Add { get; private set; }
}
```
