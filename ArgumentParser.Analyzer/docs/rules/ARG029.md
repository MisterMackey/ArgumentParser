# ARG029: Help, error, culture and tool settings of a leaf are not used by its command tree

## Summary
When a leaf command is parsed through its tree, the help, error, culture and tool settings of the `CommandApp` attribute apply. The settings of the leaf's own `ParameterCollection` attribute do not.

## Cause
This warning occurs when a class with the `ParameterCollection` and `Command` attributes is part of a tree and its `ParameterCollection` attribute sets `HelpTextGeneration`, the help argument names, `BehaviourOnError`, `UseCurrentCulture`, `EmitMcpManifest` or `EmitJsonBinder` to something other than their defaults.

Those settings still apply to the `Parse` method the leaf has of its own, but `Parse` of the root (and `CommandInfo.Parse` of the `Commands` list) uses the help argument, `BehaviourOnError` and `UseCurrentCulture` of the `CommandApp` attribute, and shows the help text the tree generates for the leaf (`CommandHelpText`). Whether the commands of the tree are described as tools (`EmitMcpManifest`, `EmitJsonBinder`) is also decided by the `CommandApp` attribute, for every leaf.

## How to fix
Move the settings to the `CommandApp` attribute, or leave them out of the leaf if they were not meant for its own `Parse`.

```csharp
// Before - Warning:
[CommandApp("app", "An app")]
public partial class App
{
	public Run? Run { get; private set; }
}

[ParameterCollection(HelpTextGeneration.GenerateTextOnly, behaviourOnError: BehaviourOnError.ThrowNever)]
[Command("run", "Run it")]
public partial class Run { }

// After - Fixed:
[CommandApp("app", "An app", HelpTextGeneration.GenerateTextOnly, behaviourOnError: BehaviourOnError.ThrowNever)]
public partial class App
{
	public Run? Run { get; private set; }
}

[ParameterCollection]
[Command("run", "Run it")]
public partial class Run { }
```
